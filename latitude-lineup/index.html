This update completely changes the selection logic to make the game intentionally deceptive. Instead of picking four random cities, the game now sorts the entire database by latitude and selects a "window" of four cities that are adjacent in the rankings. This guarantees the options are always clustered within a few degrees of each other (e.g., comparing Paris, Seattle, Montreal, and Vancouver). It also flips a coin each round to ask for either furthest North or furthest South.
